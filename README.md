# Проект E-commerce

Учебный проект по разработке интернет-магазина на Python с использованием ООП.

## Реализованный функционал (Задание 14.1)
- **Модули товаров и категорий:** Созданы изолированные классы `Product` (свойства: название, описание, цена, количество) и `Category` (свойства: название, описание, список товаров).
- **Автоматические счетчики:** В классе `Category` реализованы глобальные атрибуты класса `category_count` и `product_count`, которые автоматически ведут учет созданных категорий и всех уникальных позиций товаров в системе.
- **Подгрузка данных из JSON:** Реализована функция `load_data` для чтения и динамической инициализации объектов классов напрямую из файла `products.json`.
- **Тестирование и качество кода:**
  - Код полностью отформатирован инструментом автоматического стиля **Black**.
  - Написаны автотесты на базе **Pytest**, покрывающие проверку инициализации объектов и корректность работы глобальных счетчиков.
  - Тестовое покрытие функционального кода в папке `src/` составляет **100%**.
