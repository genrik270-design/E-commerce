# Проект E-commerce

Учебный проект по разработке интернет-магазина на Python с использованием ООП.

## Реализованный функционал

### Задание 14.1
- **Модули товаров и категорий:** Созданы изолированные классы `Product` и `Category`.
- **Автоматические счетчики:** В классе `Category` реализованы глобальные атрибуты для подсчета категорий и уникальных товаров.
- **Подгрузка данных из JSON:** Реализована функция `load_data` для инициализации объектов.

### Задание 14.2 (Новое)
- **Инкапсуляция и свойства:** Реализован приватный геттер `products` для вывода списка товаров строго по шаблону.
- **Контроль цен:** Реализован приватный атрибут цены с геттером и сеттером `price`.
- **Подтверждение снижения цены:** Добавлена интерактивная логика подтверждения пользователем снижения цены товара через консоль (`y`/`n`).

## Классы-наследники
- Созданы два класса наследников класса Product:
- «Смартфон» (Smartphone) и «Трава газонная» (LawnGrass).
- Класс «Смартфон» (Smartphone) расширен атрибутами: производительность (efficiency), 
- модель (model), объем встроенной памяти (memory), цвет (color).
- Класс «Трава газонная» (LawnGrass) расширен атрибутами: страна-производитель (country),
- срок прорастания (germination_period), цвет (color).
